# Electron excerpt provenance

This directory is a curated export from the private `apps/desktop-client` application. It is not a generated sample application and does not reconstruct the complete desktop client.

| Public file                          | Private source                                                                                                        | Adaptation                                                                                                                                                    |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/shared/contracts.ts`            | `apps/desktop-client/src/shared/types.ts`                                                                             | Retains the deployment, runtime, settings, bridge, and Windows state contracts used by this excerpt; authentication and commercial product types are omitted. |
| `src/preload/index.ts`               | `apps/desktop-client/src/preload/index.ts`                                                                            | Retains the typed `contextBridge` pattern and a bounded subset of production channels.                                                                        |
| `src/main/window-policy.ts`          | `apps/desktop-client/src/main/app.ts` (`createWindow` and external URL policy)                                        | Extracted from the larger lifecycle coordinator; keeps the production isolation and navigation rules.                                                         |
| `src/main/ipc.ts`                    | `apps/desktop-client/src/main/app.ts` (`setupIpc`)                                                                    | Extracted behind narrow runtime/settings ports; only non-authentication handlers are included and public-boundary validation is made explicit.                |
| `src/main/deployment.ts`             | `apps/desktop-client/src/main/deployment.ts`                                                                          | Keeps fail-closed target normalization and deployment-scoped identity; private runtime-config loading and capability discovery are omitted.                   |
| `src/main/deployment-link.ts`        | `apps/desktop-client/src/main/deployment-link.ts`                                                                     | Keeps the allowlisted deep-link parser; the private cloud-host equality check is omitted with the private endpoint.                                           |
| `src/main/platforms/windows/tray.ts` | `apps/desktop-client/src/main/platforms/windows/tray.ts`                                                              | Same state-to-native-menu decision logic, formatted for the standalone package.                                                                               |
| `src/renderer/snapshot-view.ts`      | `apps/desktop-client/src/renderer/app.tsx`                                                                            | Extracts production state/auth predicates and safe diagnostic-copy functions from the React renderer.                                                         |
| `tests/*.test.ts`                    | `apps/desktop-client/tests/windows/windows-platform.test.mjs` and `tests/contracts/deployment-auth-contract.test.mjs` | Ports the relevant behavior cases to Vitest so the excerpt runs independently.                                                                                |

The private application also contains the full React renderer, daemon lifecycle, authenticated local IPC transport, native packaging/signing/notarization, Windows service integration, macOS/Linux builds, and release proofs. Those parts remain private because they would expose too much of the product and operational implementation.
