# Frontend source provenance

The files under `frontend/product` are production-derived excerpts from the private Nanami monorepo. They were selected because they represent reviewable product decisions without disclosing authentication, internal API clients, infrastructure configuration, customer data, or secrets.

| Public excerpt                                  | Private source                                             | Adaptation made for this repository                                                                                                                                                                                              |
| ----------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `product/client/client-boundary.ts`             | `apps/client-web/lib/client-boundary.ts`                   | Replaced the private backend type import with the local `Edition` union. Route matching and redirect sanitation are unchanged.                                                                                                   |
| `product/client/transport-contract.ts`          | `apps/client-web/lib/control-center/transport-contract.ts` | Replaced the large generated backend `Node` type with a minimal structural type. Transport decisions and user-facing reasoning are unchanged.                                                                                    |
| `product/company/status/filters.ts`             | `apps/company-web/lib/status/filters.ts`                   | Changed local module paths only.                                                                                                                                                                                                 |
| `product/company/status/merge.ts`               | `apps/company-web/lib/status/merge.ts`                     | Changed local module paths only.                                                                                                                                                                                                 |
| `product/company/status/incident-taxonomy.*`    | `apps/company-web/lib/status/incident-taxonomy.*`          | Changed local module paths only. The catalog is the real operator failure-mode taxonomy.                                                                                                                                         |
| `product/marketing/pricing.ts`                  | `apps/marketing-web/lib/pricing.ts`                        | The source import points to the included public catalog. The standalone harness additionally preserves root-relative CTA destinations; validation, remote fallback, filtering, and model construction remain production-derived. |

Root-relative defaults keep the standalone review harness usable without environment-specific URLs.                                                        |

Navigation data and algorithms are unchanged.                                                                                                                  |

The files in `frontend/app` and `frontend/components` are a deliberately small review harness. They render these modules without recreating the private BFF, authentication, or generated API layer. Sample runtime records in that harness are fictional and use documentation-reserved IP addresses.

The Marketing page follows the private app's server/client boundary: the Server Component resolves configuration and builds the pricing model, while the Client Component receives only serializable data needed for billing-period interaction. Example deployment values live in `.env.example`, not in component source.

This mapping is intentionally explicit: reviewers can distinguish production-derived logic from the public presentation harness without relying on an unverifiable claim.
